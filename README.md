# HOOPS

Interactive multi-game basketball arcade attraction.

## Games

- Connect 4 Hoops
- 60 Second Shootout
- More games to come

## Hardware

- 7 basketball hoops
- Break-beam sensors
- Arduino Mega
- Raspberry Pi production computer
- Projector/display

## Development

Developed on macOS using:

- VS Code
- Git
- Node.js
- JavaScript
- Arduino
